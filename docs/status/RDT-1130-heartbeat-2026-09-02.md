### O1 Design Library — ConfirmDialog Composition Pattern (`packages/ui/src/ConfirmDialog/`)

Continuing the durable next-actions list from the RDT-1104 tranche 3 heartbeat (2026-09-01) — item: *confirm-dialog composition pattern (danger variant)*.

**`ConfirmDialog.svelte`** — first composition-pattern component, built from `Dialog` + `Button` rather than a from-scratch implementation:

| Aspect | Detail |
|--------|--------|
| Semantics | Confirm button fires `onconfirm` **then** `onclose`; cancel button fires `onclose` only; Escape / backdrop / close-X fire `onclose` only. |
| Destructive safety | A dismissal path can **never** trigger `onconfirm` — tested explicitly for Escape, backdrop click, and close button. |
| `danger` prop | Switches confirm button to `Button variant="danger"` (`bg-desktop-error`); default is `primary`. |
| `confirmDisabled` | Supports in-flight async states; disabled confirm is skipped by the Dialog focus trap; click is inert. |
| Focus | Focus moves to the **cancel** button on open (safe default so Enter can't accidentally confirm a destructive action). Runs after Dialog's own focus effect (child effects run first in Svelte 5). |
| A11y | Inherits `role="dialog"`, `aria-modal`, `aria-labelledby`/`aria-describedby`, focus trap + restore from Dialog; actions wrapped in `role="group"` with `aria-label="Confirmation actions"`. |
| Extensibility | Optional `children` snippet/string rendered above the actions (e.g. "type DELETE to continue" gate); `size`, `id` prefix, `closeOnBackdrop`/`closeOnEscape`/`closable` pass through to Dialog. |
